# archive/phase2-zk

Archived Phase 2 privacy work and legacy contracts.

This folder keeps the experimental / deferred ZK path out of the active demo surface while preserving the code for future work.

## Contents
- `contracts/` — legacy smart contracts not used by the live RobRulesVoting demo
- `circuits/` — archived Circom circuit work and generated artifacts
- `test/` — legacy tests for archived contracts

## Current live path
The active Sepolia demo uses `contracts/RobRulesVoting.sol` and the frontend in `frontend-app/`.
