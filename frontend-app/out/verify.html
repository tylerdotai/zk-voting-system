Verify a ZK Proof

Paste a proof JSON (proof + publicSignals) generated off-chain to verify it without sending a transaction. Uses the Groth16 verifier loaded from the Sepolia deployment.

Expected format:

{
  "proof": {
    "pi_a": [
      "0",
      "0"
    ],
    "pi_b": [
      [
        "0",
        "0"
      ],
      [
        "0",
        "0"
      ]
    ],
    "pi_c": [
      "0",
      "0"
    ]
  },
  "publicSignals": [
    "0",
    "0",
    "0"
  ]
}
